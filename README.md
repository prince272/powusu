# Prince Owusu

Personal portfolio for Prince Owusu, a Ghana-based software engineer building thoughtful products with .NET, TypeScript, React, and Next.js.

## Highlights

- Static profile site with no application server or API dependency.
- HeroUI v3 components with Tailwind CSS v4 and React 19.
- Selected projects, categorized skills, professional FAQs, and contact links.
- Grouped credentials, including the University of the People Associate of Science in Computer Science certificate.
- Downloadable CV and certificate documents under `src/POwusu.Client/public/documents/`.

## Run locally

```bash
cd src/POwusu.Client
npm install
npm run dev
```

Build for production with `npm run build` and serve it with `npm run start`.
